Python lernen

Eine Nachricht ausgeben

Mit print() zeigst du Text auf dem Bildschirm an.

Beispielcode:

print("Hallo, Road Runner!")

Das Ergebnis ist: Hallo, Road Runner!

Werte merken

Eine Variable speichert einen Wert unter einem Namen.

Beispielcode:

snack = "Keks"
print(snack)

Hier merkt sich snack den Text „Keks“.

Eine Entscheidung treffen

if führt eingerückten Code aus, wenn eine Bedingung stimmt.

Beispielcode:

if hunger:
    print("Zeit für einen Keks!")

Code wiederholen

Eine for-Schleife wiederholt Anweisungen.

Beispielcode:

for runde in range(3):
    print("Laufen!")

In dieser Lektion

  • Ausgaben mit print()
  • Variablen
  • Bedingungen mit if
  • Schleifen mit for

Die Beispiele sind vereinfachte Lernbeispiele. Sprich sie gern mit jemandem durch.
